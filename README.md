# BacSmart — Système Intelligent pour Accompagner les Candidats au BAC

Site vitrine du projet **BacSmart**, développé dans le cadre du module Atelier Créatif — Groupe ISI, Avril 2026.

##  Description

BacSmart est une plateforme numérique intelligente dédiée aux candidats au Baccalauréat. Elle propose :

- **Cours & Fiches de révision** par matière et par série
- **Quiz & Exercices interactifs** avec correction automatique
- **Suivi de progression** personnalisé
- **Orientation & Conseils BAC**
